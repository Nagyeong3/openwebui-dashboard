# OpenWebUI Analytics v2

React + TypeScript + Vite로 새로 구축한 프런트엔드입니다. 기존 Streamlit 코드 및 폐쇄망 운영 소스를 대체 설치한 상태가 아닙니다.

## 현재 상태 (2026-10-21)

- 구현 및 로컬 검증 대상: 개요, 사용자/팀/팀장 분석, 토큰 사용량, 운영 업데이트 화면.
- 기본 라이트 + 다크 테마, 모션 감소 설정, 차트 확대/교차 필터, 검색 가능한 종속 조직 필터, URL 상태, 사용자 상세 패널.
- 전체 DB 사용자 명부에 사용량을 연결합니다. 기간 내 사용량이 0이어도 사용자/팀장 전체 순위에서 표시합니다.
- **기본 실행은 합성 데모 데이터**입니다. 실사용자의 이름·조직·DB·키가 포함되어 있지 않습니다.
- 실제 API 어댑터는 아직 연결되지 않았습니다. 공개 저장소에는 현재 폐쇄망 FastAPI 응답 스키마가 없습니다.
- 운영 업데이트는 데모에서만 시뮬레이션합니다. 실제 업데이트 작업이나 DB 복사를 실행하지 않습니다.

## 실행

Node.js 22.12 이상 (검증 환경: Node 24), npm이 필요합니다. Node 16에서는 빌드하지 마세요.

```sh
cd frontend-v2
npm ci
npm run dev
```

브라우저에서 터미널에 표시되는 개발 서버 주소로 접속합니다.

```sh
npm test
npm run build
```

`dist/` 전체가 정적 배포 산출물입니다. 화면 폰트, 차트, 아이콘을 함께 번들링하므로 운영 브라우저에서 외부 CDN이 필요하지 않습니다.

## 데이터 및 코드 경계

| 파일 | 책임 |

| `src/mock.ts` | 고정된 합성 DB 사용자 및 일별 집계 |
| `src/domain.ts` | 전체 DB 명부 기반 집계, 조직 필터, 0건 순위, CSV |

| `src/styles.css` | 디자인 토큰, 테마, 반응형, 인쇄 |

계약 및 폐쇄망 연결 절차는 [API_CONTRACT.md](../docs/DASHBOARD_V2_API_CONTRACT.md), 확정 요구사항과 검증 기록은 [DASHBOARD_V2.md](../docs/DASHBOARD_V2.md)를 참고하세요.

## 사용 방법

- 차트 막대/도넛/범례 버튼을 클릭하면 조직·카테고리·모델 필터가 적용됩니다. 선택 칩의 × 또는 초기화로 해제합니다.
- 사용자 분석에서 `팀장` → `전체 N명`을 선택하면 0건 팀장까지 조회합니다. 기본 Top 10은 내림차순 10명입니다.
- 질문/토큰 정렬 버튼을 눌러 오름차순으로 바꾸면 0건 사용자부터 확인할 수 있습니다.
- CSV는 현재 페이지의 10행이 아니라 필터에 맞는 전체 사용자 행을 내보냅니다. 팀 보기에서도 사용자별 원본 집계 CSV입니다.
- PNG는 현재 표시 화면, PDF는 브라우저 인쇄입니다. 전체 페이지의 모든 페이징 행을 자동 인쇄하는 기능은 아닙니다.
- 기간/조직/모델/카테고리/현재 화면은 URL로 복원합니다. 테마는 브라우저에 저장합니다.

## 실제 API 연결

`.env.example`을 참고해 `.env.local`에 `VITE_DATA_MODE=api`를 설정한 뒤 빌드합니다. `VITE_*`에는 비밀키를 넣지 마세요. 모드/주소 변경 후에는 재빌드해야 합니다.

현재 정규화 계약인 `GET /api/dashboard/v2/snapshot` 어댑터를 FastAPI에 구현하거나, 실제 응답 확인 후 `src/api.ts`의 디코더를 교체해야 합니다. 그 전에는 API 모드가 오류를 보여주는 것이 정상입니다. API 오류 시 모의 데이터로 대체하지 않습니다.

실제 운영 환경에서 토큰 로그가 많다면 모든 기간의 행을 한 번에 내려주지 말고 요청 기간에 맞는 집계/서버 페이징으로 어댑터를 확장하세요.

## 폐쇄망 배포

1. 인터넷 개발 PC에서 `npm ci`, `npm test`, `npm run build`.
2. `dist` 폴더 전체를 승인된 절차로 반입합니다. `assets`의 해시 파일을 선택적으로 복사하면 안 됩니다.
3. 운영 서버의 기존 정적 프런트 폴더를 백업한 뒤 새 `dist` 전체로 교체합니다.
4. 정적 서버가 `index.html`을 제공하도록 설정합니다. API는 같은 origin의 `/api` 경로로 FastAPI에 reverse proxy 하는 구성을 권장합니다.
5. 정적 운영에는 Node/npm/node_modules가 필요 없습니다. 폐쇄망에서 다시 개발·빌드하려면 맞는 Node 버전과 잠금파일에 맞는 의존성 반입이 별도로 필요합니다.
6. 데모 빌드는 운영 API와 연결되지 않습니다. 실제 데이터 어댑터 검증 전 운영 배포를 완료했다고 간주하지 마세요.

서버 원본 코드를 보내지 않아도, 비식별화한 API 스키마/한 건의 응답으로 어댑터를 검토할 수 있습니다.
