# Dashboard v2 — 확정 요구사항과 유지보수

2026-10-21, Asia/Seoul. 이 문서는 신규 v2 구현에 대한 기록입니다. 기존 폐쇄망에 적용됐다는 의미가 아닙니다.

## 사용자 확정

- 신규 React/Vite/TypeScript 프런트엔드 + 기존 FastAPI 연동 방향.
- 1차: 공통 레이아웃, 개요, 사용자 현황, 토큰, 운영 업데이트.
- 라이트 엔터프라이즈 디자인, 다크모드 필수.
- 부드러운 페이지/카드/숫자/차트 전환, 차트 교차 필터, 상세 패널, skeleton, 모션 감소 지원.
- 본부 → 팀 → 직급 종속 검색 필터, 칩/초기화, URL 상태.
- **0건 DB 사용자도 모든 사용자 목록/순위에 포함**. 0건 팀장도 전체 순위에서 반드시 보임.
- OpenWebUI DB가 사용자 기준. CSV-only 사용자를 추가하는 방식 금지.
- 기존 데이터 경로를 먼저 유지하고 OpenWebUI API 전환은 후속 단계.
- GitHub `feat/dashboard-v2` 브랜치에 코드/문서 보관.

화면 크기/내보내기에 대한 별도 선택은 없었으므로 데스크톱 우선 반응형, CSV/PNG/인쇄 PDF를 기본값으로 구현했습니다.

## 구현 규칙

- 전체 DB 명부를 왼쪽 집합으로 놓고 일별 사용량을 합산합니다. 활동 집계에서 시작해 사용자 목록을 만들지 않습니다.
- 순위: 질문 또는 토큰 내림차순 → 이름 → 사용자 ID. 화면의 정렬 버튼으로 오름차순 전환 가능.
- 팀장: 보강된 직급에 `팀장`이 포함된 DB 사용자. 실제 직급 코드가 다르면 어댑터에서 명시적으로 변환합니다.
- Top 10은 10명을 초과하지 않습니다. 나머지 0건 팀장은 `전체 N명`에서 표시합니다. 개요에는 상위 5명 미리보기만 표시합니다.
- 활성 사용자/팀은 선택 기간에 질문이 있는 DB 사용자/그 사용자 소속 팀입니다.
- 미식별 LiteLLM 요청은 전체 토큰에 포함, 조직 조건 선택 시 제외, 미식별 요청 KPI로 구분합니다.
- 비교 기간이 수집 범위 밖이면 증감률을 감춥니다. 0 분모에 임의의 100%를 붙이지 않습니다.
- 질문 추이의 부드러운 곡선은 시각 보간일 뿐 추가 관측값이 아닙니다. tooltip 값은 일별 집계입니다.
