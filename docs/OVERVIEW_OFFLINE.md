## 구현 상태

신규 API 모드 구현: 확정 시안 기준 개요 화면과 `GET /api/dashboard/v2/overview`를 추가했습니다. 기존 사용자 페이지와 같은 테마/컴포넌트를 사용합니다. 기본 진입은 개요이며, 메뉴는 개요와 사용자로 정리했습니다. 팀별 현황/팀장 사용량의 별도 페이지는 제거했습니다. 후속 기능 메뉴는 준비 중으로 표시하며 실행되지 않습니다. 기존 데모 모드는 역사적 합성 화면이며 이번 변경은 `npm run build:api`로 사용합니다.

- 활성 사용자, 총 질문 수와 이전 동일 길이 기간 대비 증감률, 전체 사용자 수, 총 채팅방 수, 파일 첨부 질문, 평균 질문/채팅방, 활성 팀장.
- 일별 질문 추이: 전체 사용자 role=user 메시지 기준, 한국 시간 날짜 경계, 0건 날짜 포함. 표/그래프 독립 전환. 표는 30일 단위로 나누며 CSV에는 전체 날짜가 포함됩니다.
- 팀장 Top 10: 조직 매핑 직급에 ‘팀장’ 포함, 질문 수 내림차순, 동률은 이름/ID 순서. 사용량 0 포함. 팀장이 10명보다 많으면 상위 10명만 표시합니다.
- ‘전체 보기’: 사용자 탭에 팀장만 보기 필터를 적용하고 질문 많은 순/첫 페이지/50명씩 표시. 실제 개요 조회 시작·종료일을 유지합니다. 전체 기간이면 전체 기간을 유지합니다. 조직/검색 조건은 초기화됩니다. 필터를 해제하면 전체 사용자로 돌아갑니다. 0건 팀장도 전체 순위/상세/전체 CSV에 포함됩니다.
- 토큰/비용과 카테고리는 영역만 구현되어 있습니다. 값은 null/대시와 연동 준비 중으로 표시합니다. LiteLLM 수집·임베딩 분류는 아직 미구현입니다. 질문 원문은 API에서 받지만 현재 캐시에 저장하지 않으며 분류 시 수집 경로 확장이 필요합니다.
- 상단 추정 비용 카드는 없습니다. 하단 비용 카드는 흰색 배경과 큰 값/전체 너비로 강조합니다.
- 리포트 CSV는 현재 개요 집계·비교 기간·전체 일별 집계·팀장 Top 10을 BOM 포함 CSV로 내보냅니다. 팀장 전체 명부 CSV는 사용자 탭의 전체 CSV를 사용합니다.

## 지표 및 기간 정의

전체 사용자 수는 현재 OpenWebUI 명부의 전체 사용자이며 기간 내 사용량 0도 포함합니다. 활성 사용자는 기간 내 사용자 질문 1건 이상입니다. 총 채팅방 수는 기간 내 사용자 질문이 존재하는 고유 chat_id 수입니다. 평균 질문/채팅방은 총 질문 수 / 총 채팅방 수이며 분모가 0이면 값 없음입니다. 활성 팀장은 매핑된 팀장 중 기간 내 질문 1건 이상인 수입니다. CSV-only 인원은 어떤 사용자/팀장 집계에도 추가하지 않습니다.

최근 기간의 마지막 날짜는 현재 시각이 아니라 마지막 성공 수집 시각의 한국 날짜입니다. 비교 기간은 선택 기간 바로 앞의 같은 일수입니다. 이전 질문 0건은 퍼센트 비교 불가, 전체 기간은 비교 없음입니다. 모든 질문은 저장된 role=user 메시지 ID 기준이며 분기 메시지를 포함합니다. 총 토큰/추정 비용과 임베딩 카테고리는 각각 별도 연동 후 제공할 예정입니다.

개요 한 요청에서 캐시의 게시된 사용자/메시지/메타를 한 번 읽고 집계합니다. 기존 스키마를 변경하지 않으며 OpenWebUI나 LiteLLM에 추가 요청하지 않습니다. 실패/진행 상태 표시에는 수집 상태를 사용합니다. CSV 변경은 다음 조회 때 반영됩니다.

## 폐쇄망 반입 및 실행

확정된 개발 경로는 프로젝트 `D:\project\oui-dashboard-v2`, 이미 설치한 Conda 환경 `D:\project\oui-env-v2`입니다. 환경을 재설치하거나 이동하지 않습니다.

1. Uvicorn 창에서 Ctrl+C로 서버를 종료합니다.
2. 기존 `backend_v2`와 프런트 `dist` 폴더를 별도 이름으로 백업합니다. **.env, data, dashboard-v2.sqlite3, users.csv와 Conda 환경은 유지**합니다.
3. 반입 ZIP을 별도 폴더에 해제합니다. `backend_v2` 전체와 `frontend_v2\dist` 전체를 대상 프로젝트에 반영합니다. 기존 dist는 이름을 바꿔 보관하고 새 dist로 교체하여 해시 assets를 혼합하지 않습니다.
4. 루트 `.env`의 `DASHBOARD_FRONTEND_DIR`이 새 `index.html` 폴더를 가리키는지 확인합니다. 프런트 폴더 이름이 `frontend-v2`라면 실제 폴더에 맞게 경로만 조정합니다. 기존 성공 캐시 경로를 변경하지 않습니다.

CMD:

```bat
conda activate D:\project\oui-env-v2
cd /d D:\project\oui-dashboard-v2
python -m pip check
python -m unittest discover -s backend_v2\tests -v
python -m backend_v2.cli status
python -m uvicorn backend_v2.app:create_app --factory --host 127.0.0.1 --port 8011
```

이미 full 성공 캐시가 있으면 다시 full을 실행할 필요가 없습니다. 최신 내용을 가져오고 싶을 때 별도 터미널에서 `python -m backend_v2.cli sync --kind quick`을 실행합니다. 이번 코드 변경에는 새 Python/Node 런타임 의존성이 없으며, 빌드 포함 ZIP이면 폐쇄망 npm 설치도 필요 없습니다.

브라우저: `http://localhost:8011/?screen=overview`. Ctrl+F5로 새로고침합니다. 인증을 설정했다면 화면 설정에서 DASHBOARD_API_TOKEN을 입력하며 OpenWebUI 키를 브라우저에 넣지 않습니다.
